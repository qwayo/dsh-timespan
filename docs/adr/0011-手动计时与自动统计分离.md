# 手动计时与自动统计分离

2026-11-16，用户确认新增手动正计时和倒计时。手动计时反映用户主动划定的一段时间，既可能与界面活跃重叠，也可能与 Agent 的任务重叠，不能直接解释为现有的在线、活跃或任务时长。

手动计时采用独立口径，不补写或累加到自动采集的三类时长中；允许两类计时在同一时段重叠。TimeSpan 同时提供一只全局计时器，切换工作区或会话时保持同一计时状态。

计时按实际经过的时间计算，只有用户手动暂停才停止累计；页面切换、刷新、电脑休眠或退出 DSH 后，恢复时仍延续同一次计时。DSH 退出期间不发出提醒，重新打开后判断倒计时是否已经到期。仅保留当前状态和最近一次完成结果，不建立历次手动计时记录列表。

备份包含最近一次完成结果，导入保留本机已有结果，不启动或覆盖正在运行的计时。清空数据同时清除计时数据并停止当前计时；恢复初始设置保留计时数据。

这一边界保留了自动统计原有的观测含义和并发计算规则，避免同一段时间被用户操作再次计入。手动计时的状态与结果需要独立表达，不能复用现有任务记录冒充 Agent 的任务。

## 2026-11-23 计时历史与预设

手动计时在同一存储域保留最近 30 条完成记录，兼容读取旧版单条结果。新完成的计时记入历史，重置和暂停不产生新记录。完成状态和到期提醒仍指向本机最近一次完成记录。计时面板按完成时刻列出历史，实际用时只计算运行中的计时段。

JSON 备份包含计时历史。导入按记录 ID 去重，用剩余容量补充本机历史，保留本机计时、结果和待领提醒。导出继续带有旧版可读的单条记录。清空数据会清除历史，恢复初始设置保留历史。

默认倒计时属于插件设置，菜单和面板共用，范围为 1 至 10,080 分钟，首次启用及恢复初始设置为 25 分钟。
