# AI 分析范围与自身任务隔离

2026-11-16，用户确认 TimeSpan 的 AI 分析同时覆盖统计解读与会话内容总结。分析默认使用仪表盘所选日、周、月的统计与同期内容，生成前可缩小到指定工作区或会话；会话依据包括主对话、必要的工具结果与关联子代理的最终结果，并保留来源会话入口。统计指标沿用现有领域口径，正文总结不改变子代理在统计汇总中的处理方式。

TimeSpan 自身生成报告的任务不进入任务时长，也不成为后续报告的分析对象，以免分析行为反过来扩大统计或循环总结自己。其他同时运行的任务照常统计，在线和活跃仍按原有规则记录。该排除只针对能够明确归属于本插件报告生成的任务，不能排除普通会话中的用户工作。

分析使用独立设置的 Provider 与模型，选项来自 DSH 已配置的模型目录，不跟随当前会话的模型选择。模型调用复用宿主配置，不另建一套凭据。选择报告模型不能改变会话正在使用的模型。

报告按日、周、月分别保留最近一份成功结果，标明实际日期、筛选范围、模型和生成时间；重新生成失败时保留旧报告。备份包含报告，导入保留本机已有结果；清空数据同时清除报告，恢复初始设置保留报告。

这些边界将用户工作、分析输入和分析自身的运行区分开。报告必须区分有统计数据支持的变化、会话内容记载的工作以及模型提出的推测；不能仅凭时长断言工作质量或完成结果。

实现采用独立 `analysis` 存储表，避免大段材料随着在线心跳反复写入元数据。模型调用前先持久化原生 DSH 请求事件前缀，再从存储读回并用 `sessions.prepare()` 校验可重放的请求头与消息；精确匹配后才调用已准备好的模型路由。前缀不发布为普通会话，也不启动带工具的 Agent，因此不会产生需要再从统计中扣除的普通任务。

私有请求前缀仅保留最近一次请求和三个周期各自最近成功报告的对应请求，受大小限制，不随报告备份导出。清空数据会删除这些前缀。相比另建持久会话，这个选择使报告与其材料受同一个清理边界管理，同时保留模型输入的重建与核验能力。

回顾图表与报告一起保存生成时的统计快照，限于汇总、趋势和有界工作区字段，不包含原始会话材料。旧报告可从其匹配的成功请求恢复快照，缺少或范围不符时不使用当前统计补图。快照随报告备份与 Markdown 导出，避免历史结论旁展示持续变化的新数据。
